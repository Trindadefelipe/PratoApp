## 🎯 Regras de Integração da Equipe
1. **Independência dos CRUDs:** Cada integrante é o responsável direto pelo ciclo de vida completo do seu módulo (tabela no banco PostgreSQL, rotas na API Express, telas e validações no React Native Expo).
2. **Integração Real:** Todas as telas consumirão a API RESTful centralizada, sem dados estáticos/mocados na entrega final.
3. **Pipeline de Data Science Colaborativo:** O notebook Jupyter conterá seções delimitadas e identificadas com os commits e autorias de cada etapa do pipeline.
